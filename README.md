## 🚀 Live Demo

**Try the deployed Reinforcement Learning-based Smart Grid Energy Routing System!**

- **Live Dashboard:** [Open Dashboard](https://elnino-smart-grid-dashboard.onrender.com)
- **Backend API:** [FastAPI Backend](https://rl-smart-grid-energy-routing-el-nino.onrender.com)


### How It Works

1. Enter electricity demand for different cities and consumer categories.
2. Specify the available electricity supply.
3. The trained PPO-based Reinforcement Learning agent determines an energy allocation strategy.
4. Compare the RL agent against traditional rule-based allocation methods.
5. Analyse energy distribution, shortages, and performance metrics.

### Technology Stack

- **Reinforcement Learning:** Proximal Policy Optimization (PPO)
- **RL Environment:** Gymnasium
- **RL Framework:** Stable-Baselines3
- **Backend:** Python, FastAPI
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render
- **Dataset:** Synthetic Maharashtra Electricity Dataset

### Deployment

The frontend and backend are deployed as separate Render services and communicate through REST API requests.

*Note: The electricity dataset is synthetic and was generated for academic and research purposes.*
