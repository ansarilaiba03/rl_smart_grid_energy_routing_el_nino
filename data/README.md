# Dataset

The complete dataset used in this project is available on Kaggle:

[Maharashtra Electricity Dataset (Synthetic)](https://www.kaggle.com/datasets/laiba02/maharashtra-electricity-dataset-synthetic)

## Important Note

This is a **synthetic (artificially generated) dataset** created for academic and research purposes.

It does **not** represent official or real-world electricity data from Maharashtra and should not be used for actual power-grid planning or decision-making.

## Dataset File

`maharashtra_electricity_2015_2026.csv`

## Purpose

The dataset is used for developing and evaluating a Reinforcement Learning-based smart-grid energy allocation system for mitigating power shortages during El Niño conditions.
